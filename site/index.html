Get started

Add the package, drop the widget in, read the selected country.

import 'package:flutter_flag_selector/flutter_flag_selector.dart';

FlagSelector(
  // Optional: defaults to the device's country.
  flagSelectorInitialCountry: 'fr',
  flagSelectorLanguageCode: 'fr',
  flagSelectorOptionType: FlagSelectorOptionType.modalBottomSheet,
  onFlagSelectorCountryChanged: (country) {
    print('${country.name} ${country.dialCode}');
  },
)
  • Pick a mode with flagSelectorOptionType: modalBottomSheet, dialog, popupMenu or draggableSheet.
  • Change the language of country names with flagSelectorLanguageCode.
  • Limit the list with flagSelectorCountries; search stays within it.
  • Query the data directly with CountryService: by code, currency, region or free text.
  • Full API reference in the README and on pub.dev.
